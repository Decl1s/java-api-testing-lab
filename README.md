# Java API Testing Lab

[![Java API checks](https://github.com/Decl1s/java-api-testing-lab/actions/workflows/tests.yml/badge.svg)](https://github.com/Decl1s/java-api-testing-lab/actions/workflows/tests.yml)

Учебный проект по автоматизированному тестированию REST API на Java. Предметная область — постановка файлов в очередь обработки. Стенд не сканирует файлы: принимает только метаданные и хранит задания в памяти.

## Что проверяется

Создание и чтение задания, отмена и повторная отмена, авторизация, типы данных, обязательные поля, граничные значения, изоляция заданий, формат ответа и заголовки. Все проверки отправляют реальные HTTP-запросы локальному стенду. Каждый тест получает новый сервер и пустое хранилище; порт выбирает ОС.

## Запуск

Нужны JDK 17+ и Maven 3.8+. Из корня репозитория:

```sh
mvn test
```

Отчёты: `target/surefire-reports/`. Тесты не требуют интернета во время выполнения; при первой сборке Maven скачивает зависимости.

## Проверка чувствительности тестов

```sh
mvn -DdemoBug=true test
```

Режим намеренно отключает верхнюю границу размера. Два варианта TC-03 должны упасть: 4097 и 2147483647 KB. Это внесённый учебный дефект, а не найденная ошибка внешнего продукта. Обычный запуск должен проходить. После демонстрации выполните обычный `mvn test`.

## Структура

- `FixtureServer` — локальный объект тестирования: маршруты, валидация, состояние заданий.
- `ApiClient` — клиент HTTP с ограничением времени ожидания.
- `JobsApiTest` — сценарии и ожидаемые результаты.
- `docs/contract.md` — требования, определяющие ожидаемые результаты.
- `docs/test-plan.md` — риски, приоритеты и границы проверки.
- `docs/test-cases.md` — соответствие ручных сценариев автотестам.
- `.github/workflows/tests.yml` — запуск Maven и сохранение отчётов на GitHub.

## Ограничения

Статический ключ для локальной демонстрации. Нет реального сканирования, БД, очереди, параллельной обработки и нагрузочных проверок. Повторный POST создаёт новое задание; идемпотентность создания не заявлена. Валидация неизвестных дополнительных полей не заявлена. GitHub Actions: первый запуск прошёл успешно 6 октября 2026. [Отчёт CI](https://github.com/Decl1s/java-api-testing-lab/actions/runs/37438308968).

Проект подготовлен с помощью AI. Для обсуждения на собеседовании нужно понимать клиент, проверки, фикстуру и требования; генерация проекта сама по себе не означает владение стеком.
